# Eritrea — evidence dossier

**First pass, thin — modern system barely documented, deep colonial
history is the only substantial content.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Eritrea).

- Current system: no dimensions, colors, or serial format found — genuine
  source gap, would need a dedicated second-pass search rather than a
  deeper read of this article.
- Colonial history (1913-1941) closely parallels Somalia's — same Italian
  East Africa administrative lineage, same `AOI` tricolor-square format
  1937-1941, "ER" abbreviation throughout. Worth treating Eritrea/Somalia/
  Ethiopia's colonial-era plates as one connected historical thread rather
  than three unrelated legacy formats, if that period is ever modeled.
