# Togo — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Togo).

- 520×110mm, `1234-AB` (or two-row `AB/1234`). White/dark-blue-or-black
  private, yellow/red commercial, light-green/white state transport
  (`G/A 1234` — government-index letter), blue/white diplomatic
  (`12CD34`).
- **No regional coding**, same as Benin — a 2nd West African country with
  this trait, strengthening that as a real regional pattern rather than
  coincidence.
- Current system since 2007.
