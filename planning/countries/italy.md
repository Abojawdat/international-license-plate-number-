# Italy — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Italy), [matriculasdelmundo.com/en/italy.html](https://matriculasdelmundo.com/en/italy.html).

- Format: 2 letters + 3 digits + 2 letters. **Different front (360×110mm)
  and rear (520×110mm) dimensions** — same "different size by face" case
  as Tunisia, a 2nd confirmed country with this. Square variant 297×214mm.
- Left euroband "I"; right blue stripe shows registration date above,
  region below — another cosmetic-ish right-side region field, worth
  comparing against France's explicitly-cosmetic version.
- Military/fire: red on white, `EI`/`VF` prefix. Diplomatic: blue letters,
  black numbers, `CD`/`CC` prefix.
