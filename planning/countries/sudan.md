# Sudan — evidence dossier

**Second pass attempted across 3 more targeted searches, category data
confirmed genuinely unreachable by general search — a ResearchGate table
("Sudanese Vehicles Plates Types") almost certainly has the answer but
sits behind a figure/paywall this tool can't open.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Sudan), [matriculasdelmundo.com/en/sudan.html](https://matriculasdelmundo.com/en/sudan.html), plus [worldlicenseplates.com/world/AF_SUDA.html](http://www.worldlicenseplates.com/world/AF_SUDA.html) (fetch blocked by a self-signed certificate, not a content gap — worth a direct browser visit if this dossier gets prioritized).

- 320×160mm. Format `1L-2345` — state letter embedded in the serial itself
  rather than as a separate region code field.
- "SUDAN" in English and Arabic at top.
- Category colors: not found in this pass at all — sources acknowledge
  multiple plate types exist by color but don't enumerate them.
- Sudan's active civil conflict (since 2023) makes this one of the
  highest-priority "current system may not be current" caveats in the
  whole tracker, alongside Syria/Yemen/Afghanistan/Myanmar.
