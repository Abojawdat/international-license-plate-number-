# Azerbaijan — evidence dossier

**First pass, one major finding.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Azerbaijan).

- EU-size. Format `11-PO-749`, department-code prefix (multiple codes can
  serve one city, e.g. Baku = 10/77/88/90).
- Colors: black/white standard, blue public transport, red diplomatic
  (with a numeric country code embedded, e.g. `001 D 001` = Turkey), yellow
  foreign-resident (`H`-marked).
- **Since Sept 2011: an RFID microchip embedded in the physical plate**,
  positioned below the national flag — a step beyond every other digital-
  security finding so far (Armenia's Data Matrix, Romania's barcode/
  hologram, Peru's destructive hologram): this is an embedded electronic
  tag, not a printed pattern. Worth its own tier in the security-features
  taxonomy, not lumped in with printed codes.
- Previously Soviet GOST 3207-77 standard (1977-1993) with Cyrillic —
  another ex-Soviet-standard legacy format, same family as several Central
  Asian/Eastern European countries.
