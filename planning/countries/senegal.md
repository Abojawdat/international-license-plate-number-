# Senegal — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Senegal).

- Current (2019-present): 520×110mm, black on white, blue country strip
  (flag + "SN"), region code (e.g. DK = Dakar) + `AA 999 AA`.
- Previous (1989-2019): same size, **inverted colors** (white on blue) —
  a clean, well-documented 2-era history, current vs. legacy like Iraq's
  own model.
- Motorcycles: 240×130mm, smaller text.
