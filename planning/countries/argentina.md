# Argentina — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Argentina), [matriculasdelmundo.com/en/argentina.html](https://matriculasdelmundo.com/en/argentina.html).

- Confirms `brazil.md`'s finding directly: Argentina uses the same
  Mercosur-standard blank (400×130mm, `AA 000 AA`, blue top strip with
  flag + Mercosur logo, country name centered) since April 1, 2016 — this
  is a real shared `PlateBlank`, not just a coincidentally similar size.
  Only the country name/flag on the strip differs from Brazil's.
