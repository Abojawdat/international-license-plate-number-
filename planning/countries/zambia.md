# Zambia — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Zambia).

- 520×110mm. Format: first letter always `A`, next 2 letters = registration
  center, then 4 digits.
- Colors: black/white standard, red/red border = public service vehicles,
  red background = dealers, yellow horizontal stripe on white = state-owned.
- **German FE-Schrift typeface** — the same anti-counterfeiting typeface
  Brazil's Mercosul standard uses (see `brazil.md`), confirming FE-Schrift
  is a real cross-country shared typeface option worth having available,
  alongside Mongolia's plain-Calibri finding, as a second "known, reusable"
  typeface case instead of every country needing a bespoke vector face.
- ZS (Zambia Standards) logo + coat of arms on the left.
