# Japan — evidence dossier

**Status: first pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Japan) plus several enthusiast/JDM-import sites (ZervTek, japan-license-plate.com) agreeing on the scheme.

## What's known
- **Three scripts on one plate**: kanji (prefecture name, top line), a
  hiragana character (bottom line), and Arabic numerals (class code,
  registration-office code, serial). The most script-diverse plate found so
  far — more than China's kanji+Latin, since this adds hiragana too.
- Two sizes: medium 330×165mm (standard, matches Kuwait's 335×155-ish
  bracket loosely) and large 440×220mm (heavy vehicles/high-capacity buses).
- Colors by use, not just ownership: white+green text = private (over
  660cc), yellow+black text = kei cars (under 660cc, a vehicle-*class*
  distinction unique to Japan so far), green = taxi/public transport, black
  = commercial cargo carrying non-passenger goods.
- Top-right vehicle-classification number (0-9 prefix) — a numeric class
  code embedded in the plate itself, separate from the region/prefecture
  code.

## Open questions
- Exact hiragana character meaning/allocation.
- Whether kei-car yellow plates are a *category* (like Iraq's) or a
  *physically distinct smaller blank* — not confirmed, matters for the
  geometry model.
