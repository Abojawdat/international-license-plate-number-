# Cyprus — evidence dossier

**First pass, one political-territory finding.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Cyprus).

- Current since 2013: 520×110mm, `ABC 123`, letters restricted to
  "ABEHKMNPTXYZ" (cross-script-compatible with Greek, same principle as
  Greece's own restriction — expected, given the shared alphabet/history,
  but confirms the pattern isn't unique to mainland Greece).
- Colors: white standard, yellow taxi, dark-red rental, white/yellow
  commercial trucks (front/rear split).
- **Northern Cyprus (a breakaway/disputed territory) continues using the
  island's own *older* 1973-1990 Cypriot format** rather than either the
  current Republic of Cyprus format or a wholly separate design — a
  breakaway territory freezing a shared predecessor format rather than
  diverging entirely, a new shape for the disputed-territory case
  alongside Abkhazia/Transnistria/Somaliland already flagged.
