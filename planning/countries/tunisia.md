# Tunisia — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Tunisia), [matriculasdelmundo.com/en/tunisia.html](https://matriculasdelmundo.com/en/tunisia.html).

- Front 450×100mm, rear 520×110mm — **different sizes front vs. rear on
  the same vehicle**, a new case (UK/Algeria vary color by face, Tunisia
  varies actual dimensions by face).
- Format `XXX تونس XXXX` — Arabic country name embedded mid-plate between
  two digit groups, not on a side band/strip like every other dossier so
  far — a fourth distinct identification-region layout shape.
- White on black (inverted from most dossiers' black-on-white default).
- Rental cars: white on blue, same format otherwise.
