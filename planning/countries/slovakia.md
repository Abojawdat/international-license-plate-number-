# Slovakia — evidence dossier

**First pass, confirms an extreme version of the drop-regional-meaning
trend.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Slovakia).

- 520×110mm. **Jan 2023: eliminated all 79 district codes entirely**,
  replacing district-based plates (1997-2022) with pure sequential
  numbering starting `AA-001AA` — a more drastic version of Estonia's
  2019 randomization and Spain's no-province design: this one removed a
  government-run district-code system outright rather than randomizing
  within it.
- Colors: black/white standard, red dealer, dark-blue/yellow diplomatic,
  green import.
- Coat of arms added 2006 after 2004 EU-mandated redesign, removed again
  by the 2023 nationwide system — a coat-of-arms add-then-drop sequence,
  a small-scale oscillation similar in shape to Slovenia's.
