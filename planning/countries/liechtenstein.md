# Liechtenstein — evidence dossier

**First pass, one striking default-color finding.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Liechtenstein).

- Front 300×80mm, rear 500×110mm or 300×160mm square — same Swiss-
  standard multi-shape system as Switzerland itself (1972: dimensions
  standardized to Swiss spec, unsurprising given the neighboring/allied
  relationship, but confirms the shared-standard pattern again).
- **The only sovereign European state confirmed issuing black plates
  (white text) as the default for all motor vehicles, since 2001** — an
  even more committed black-default case than Belgium's red-ink or
  Guyana's white/black; here black is the *field*, not just the ink, for
  ordinary passenger cars.
- Rich category-color table: light-green agricultural, light-blue
  utility/industrial, light-brown "exceptional" vehicles, black/yellow
  short-term (1-4 days — an unusually short temporary-registration
  window), yellow/black small motorcycles/e-bikes, red/white repeater
  plates (towbars — a plate for a *trailer hitch accessory*, not a full
  vehicle, a new registrable-object category).
- History: adopted Austria's system 1906 → own `L` plates 1915 → `FL`
  code 1924 → Swiss-standard dimensions 1972 — one of the oldest
  continuously-run systems found, alongside Estonia's 1907 origin.
