# Armenia — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Armenia), [matriculasdelmundo.com/en/armenia.html](https://matriculasdelmundo.com/en/armenia.html).

- 520×110mm. Black on white. Format: 2-3 digit region code + 2 letters
  (smaller size than digits — a font-size-within-plate detail not modeled
  anywhere) + 2-3 digits.
- Since Aug 2014: flag on left band, **security hologram and a
  machine-readable Data Matrix code** — the first dossier to mention an
  anti-counterfeiting digital code as part of the physical plate, distinct
  from Iraq's guilloche/micro-print security theme (which is visual-only).
