# Thailand — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Thailand), a dedicated ALPR academic PDF (Sumitomo Electric) — worth pulling directly, rare to find an industrial ALPR spec sheet.

- 150×340mm. Format: 2 Thai letters + up to 4 digits, **full province name
  spelled out in Thai script centered at the bottom** — not a code, the
  actual name, a more verbose identification approach than any other
  dossier so far.
- Colors: white = private, yellow = commercial hire, red = temporary/
  dealer, green = government.
- Requires Thai script rendering — another script family (7th distinct
  after Hanzi, Hiragana, Cyrillic, Bengali, Devanagari-pending-confirm).
