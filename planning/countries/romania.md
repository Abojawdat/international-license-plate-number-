# Romania — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Romania).

- 520×110mm standard, plus 340×200 and 240×130 variants (multi-size).
  Format `CC 12 ABC`, 42 county codes (Bucharest = `B`, with a longer
  serial than other counties given its size — same population-driven
  variance pattern as Germany/Austria/Greece's code-length rules, here
  applied to serial length instead of code length).
- EVs: green inscription. Local administration: yellow background.
- **Sept 2024 security update added barcodes and phosphorescent
  holograms** — very recent, joins Armenia's Data Matrix and Peru's
  destructive hologram as real digital/enhanced anti-counterfeiting
  measures, not just visual security print like Iraq's guilloche.
