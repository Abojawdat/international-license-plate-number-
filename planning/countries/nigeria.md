# Nigeria — evidence dossier

**Status: first pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Nigeria) plus a Nigerian car-culture site (autojosh.com) that's referenced by several other results, suggesting it's a commonly-cited local source.

## What's known
- Format: `ABC-123DE` — three letters for **Local Government Area (LGA)**,
  not state — Nigeria has 774 LGAs, a much finer-grained subdivision code
  than any other dossier so far (vs. Iraq's 19 governorates or Turkey's 81
  provinces).
- Dimensions reported as 152×300mm — **taller than wide**, an outlier
  against every other dossier gathered (everything else so far is
  landscape). Possibly a units/orientation mixup in the source; flagged
  rather than trusted.
- Colors: blue-on-white = private, red-on-white = commercial, green-on-white
  = government, black-on-white = military/paramilitary, purple = corps
  diplomatique, brown = consulate.
- State name + slogan at top center, "Federal Republic of Nigeria" at
  bottom, flag/coat of arms upper-left — a layout with *three* distinct text
  regions plus an emblem, more than Iraq's band+flag.
