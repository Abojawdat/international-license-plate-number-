# Andorra — evidence dossier

**First pass, good category coverage.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Andorra).

- 340×120mm, `A 1234`. Black/white standard, red/green dealer (`PROVA`),
  white/light-blue diplomatic, red/white special vehicles, official
  vehicles use the national tricolor directly as the design.
- Coat of arms + "AND" code on left, *Principat d'Andorra* text below the
  serial — a bilingual-feeling layout (Catalan official name spelled out)
  even though the registration itself stays Latin/numeric.
- First plates ~1930 (`AND 1234`); 1989-2011 design; current since 2011.
