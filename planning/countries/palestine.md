# Palestine — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_the_State_of_Palestine).

- West Bank: green text on white — deliberately distinct from Israel's
  yellow (see `israel.md`); sources describe this as tied to real movement
  restrictions at checkpoints, not just a design choice. Treat as a
  politically sensitive dossier — flag for the same sensitivity
  conversation as the disputed/breakaway territories in `_tracker.md`
  before building.
- Format changed July 2018: `#-####-X` (5 digits + 1 Latin letter, was
  7 digits before). Right-side strip: Latin `P` above Arabic ف (Faa',
  فلسطين) — same `ColorBandStrip`-shaped region as Iraq/Lebanon.
- No dimensions found yet. Gaza situation not covered by this source at
  all — may need separate treatment.
