# Belgium — evidence dossier

**First pass, architecturally significant.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Belgium).

- **Explicitly confirmed: "registration plates are driver specific,"
  transferred to a new vehicle from the owner's previous one.** This is a
  second, independent confirmation of Cuba's driver-bound-not-vehicle-bound
  finding (#17) — no longer a single unverified oddity, now a real pattern
  worth designing for rather than dismissing. The consequence called out in
  the source itself is telling: plate age becomes unreliable for
  inferring vehicle registration year, which matters for any validation or
  UI logic built on "the plate tells you about the car."
- 520×110mm, `1-AAA-345` since Nov 2010 (reversed from 2008-2010's
  `111-AAA`, itself reversed from 1973-2008's `AAA-111` — 3 format eras in
  under 40 years, unusually fast churn).
- **Red text on white** is the standard default — an outlier color choice
  (red as primary ink, not just an accent) not seen as a *default* anywhere
  else so far.
- Dealer: green on white with EU flag. Trailer (>750kg): `Q` prefix.
