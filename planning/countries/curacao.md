# Curaçao — evidence dossier

**First pass, one alphabet-partition finding.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Cura%C3%A7ao).

- `A 12-34`, black/white, no country code or slogan.
- **The entire alphabet is partitioned by category**: 16 specific letters
  reserved for private vehicles (A, B, D, F, G, H, J, K, L, M, N, R, S, T,
  W, Y), 3 for commercial/pickup (U, V, X), plus dedicated non-letter
  prefixes for motorcycles (`MF`), mopeds (`BF`), buses (`BUS`), taxis
  (`TX`), police (`POLIS`, the Dutch spelling), government (`C-`), antique
  vehicles (`WABI`), heavy equipment (`Z`) — the most exhaustively
  letter-by-letter category system found, going well beyond a simple
  prefix rule to a full alphabet assignment.
