# Germany — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Germany), [customeuropeanplates.com](https://www.customeuropeanplates.com/pages/german-license-plate-codes).

- 520×110mm (cars); 340×200mm two-line for trucks/buses/trailers.
- District code length (1-3 letters) is inversely tied to city size — major
  cities get single letters (B=Berlin, M=Munich, K=Köln) — a
  population-driven code-length rule, a new reason for within-country
  format variance (distinct from Egypt/Turkey/Pakistan/Malaysia's
  administrative-boundary-driven variance).
- Total characters capped at 8. Blue euroband: EU stars + "D".
- Black on white — the plain default this project already assumes.
