# Macau — evidence dossier

**First pass, one novel finding.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Macau).

- Format `MA-12-34` (prefix rotates as combinations are used, "AB" as of
  Oct 2023). White/black standard, yellow/black commercial (color swap for
  category, field stays black), black/white mopeds (`CM-` prefix,
  Portuguese "Ciclomotor" — colonial-heritage naming, joins Angola's
  Portuguese-dies finding).
- `ZA` prefix: People's Liberation Army vehicles, using mainland China's
  plate design standard *inside* Macau's system — a country's military
  literally using a different country's (well, the sovereign state's)
  plate format within the territory, a unique cross-jurisdiction case.
- **`HK` prefix: Hong Kong-registered vehicles, capped at 4,500 plates
  total** — the first confirmed *quota-limited* plate category found. Not
  a design variant, a hard numeric cap on how many can ever be issued.
- Colonial lineage: Portuguese overseas-territory standard from the 1950s,
  based on Portugal's own 1937 system.
