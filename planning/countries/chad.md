# Chad — evidence dossier

**First pass, good category coverage.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Chad).

- 520×110mm, `12A3456B` (region + type letter + digits + series letter).
  French FNI-based system since 2001 (joins Republic of Congo's identical
  FNI-derived lineage).
- Full category table: black/white regular, white/blue taxi, red temporary/
  tourist, black/yellow state vehicles, white/red police, black/yellow
  military, black/yellow gendarmes — military/gendarmes/state vehicles
  sharing one color scheme while police gets its own is a distinct grouping
  choice.
- Regional codes expanded 18→22 across 2008/2012 administrative
  reorganizations — a region-list-grows-with-real-administrative-change
  case, similar in kind to North Macedonia's gradual code additions but
  tied to actual redistricting rather than steady growth.
