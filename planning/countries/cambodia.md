# Cambodia — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Cambodia).

- Format since April 2004: class number + 1-2 Latin letters + 4 digits,
  **province name in Khmer at top, English at bottom on the same plate** —
  a bilingual-by-field layout distinct from every pattern seen so far
  (not Saudi's always-both-of-the-registration, not Iraq's
  format-determines-script; here it's specifically the region label that's
  bilingual while the serial stays Latin/digits).
- Colors: white = private, yellow = commercial, red = government, blue =
  diplomatic.
- Two concurrent sizes: "long" 140×500mm and "short" 160×320mm.
