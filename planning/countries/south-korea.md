# South Korea — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_South_Korea).

- 520×110mm. Format: 3 digits + **1 Hangul consonant + 4 digits** (8
  characters total). The Hangul character encodes vehicle type/legal status
  — a script character used as a *coded data field* embedded in the serial
  itself, not a decorative regional label like Japan's kanji or Iraq's
  band text. A new pattern for how script integrates with validation logic.
- Colors: white/black = private, yellow/black = commercial (taxi/bus),
  green/white = government/public institution.
