# French Polynesia — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_French_Polynesia).

- 520×110mm (EU standard, French stamping dies — joins Angola/Rwanda/
  Zambia/Fiji's manufacturing-heritage-tie pattern, here a live territorial
  tie rather than historical colonial one).
- Front yellow/black, rear white/black — a face-color-split case again.
- **Uses France's own overseas-territory 3-digit code system**, code
  `987` — French DOM-TOMs originally shared one code (`97`) before getting
  individual 3-digit codes; this is a numbering scheme inherited directly
  from the governing country's own internal system, not a locally
  designed one. Same pattern expected for New Caledonia (`988`, below) and
  any other French overseas territory researched later.
