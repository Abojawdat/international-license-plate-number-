# Libya — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Libya), [matriculasdelmundo.com/en/libya.html](https://matriculasdelmundo.com/en/libya.html).

- 520×110mm. Black on white. Format: 1-2 digit municipality code + dash +
  1-6 digit registration code, Latin numerals. Arabic ليبيا (Libya) in
  Naskh script, right side or top-right.
- Current series dates to 2013, post-revolution — the newest "current
  system start date" found in any dossier so far, worth noting since
  political transitions elsewhere (Syria, Yemen) suggest checking whether
  this is still actually current given events since.
