# Chile — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Chile).

- 360×130mm, black on white. Format `LL-LL*NN` since 2007 — **the Chilean
  coat of arms is embedded literally between the letter and number
  groups**, not on a side strip/band, a placement variant not seen
  elsewhere (Zimbabwe centers its emblem, but not inline within the serial
  itself like this).
- "CHILE" at bottom, international code RCH. Trailers: red text.
