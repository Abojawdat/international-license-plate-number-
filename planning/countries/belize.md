# Belize — evidence dossier

**First pass, good category coverage.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Belize).

- 152×300mm. Black/white passenger, white/black commercial (inverted from
  passenger), black/orange dealers, white/brown Defense Ministry, white/
  dark-green taxi.
- **Kept its pre-independence road code "BH" (British Honduras) even after
  the 1981 independence and 1973 renaming to Belize** — another case of a
  code outliving the political entity it originally named (joins
  Botswana's Protectorate-era codes, Namibia's South-West-Africa-era `S`).
  "C.A." (Central America) text, same regional-bloc convention as
  Guatemala/Costa Rica/Honduras.
