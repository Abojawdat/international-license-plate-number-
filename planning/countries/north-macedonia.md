# North Macedonia — evidence dossier

**First pass, one political-naming finding.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_North_Macedonia).

- 520×110mm, `AB 1234 CD`. 34 region codes added gradually (10 in 1993,
  more through 2020) — a region-code list that grows *over time within a
  stable format*, not tied to a format redesign at all, a new shape for
  "how does the region-code list change."
- Colors: black/white standard, black/country-code diplomatic, yellow taxi,
  yellow/red government, blue/rear-only police (6 digits in 2 groups).
- **Country code changed from `MK` to `NMK` in Feb 2019 following the
  Prespa Agreement** (the treaty resolving the country's naming dispute
  with Greece, renaming it "North Macedonia") — a political-treaty-driven
  code change, a new "why did the code change" reason distinct from every
  other one found (capacity, unification, misreading, crime-prevention,
  cultural). Cyrillic-letter equivalents shown on a badge alongside the
  Latin code.
