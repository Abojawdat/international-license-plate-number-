# Malaysia — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Malaysia), Motor Trader News, FreeMalaysiaToday.

- Format `ABC 1234` — first letter(s) = state, excludes I/O/Z (6th country
  with a visual-confusion exclusion list).
- **Default is white-on-black** for ordinary private vehicles — an outlier
  against nearly every other dossier so far, where black-on-white or
  white/yellow-based is the norm. Taxis are the inverted case here
  (black-on-white). Worth double-checking, but two independent sources
  agree.
- Diplomatic: red, format keyed to nationality/rank/organization — more
  structurally complex than most countries' diplomatic plates.
- Sabah/Sarawak use a second letter for sub-state area, unlike Peninsular
  Malaysia's single-letter state code — within-country format variance
  again (Egypt/Turkey/Pakistan pattern, 4th case).
- No overall plate dimensions found, only character size (40×70mm).
