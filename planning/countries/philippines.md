# Philippines — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_the_Philippines), [myltotracker.ph 2026 color-coding guide](https://myltotracker.ph/plate-number-color-coding/).

- 390×140mm (cars), 235×135mm (motorcycles, format `123ABC` reversed order
  from cars' `ABC-1234`).
- Colors: black/white = private, red/white = government, **green/white =
  electric/hybrid** (a 4th distinct EV-encoding approach — color swap like
  India, but for hybrids too, not just full EVs), blue/white = diplomatic,
  black/yellow = public utility vehicles.
- Front+rear standardized together since July 2018.
