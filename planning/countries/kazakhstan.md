# Kazakhstan — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Kazakhstan), [egov.kz](https://egov.kz/cms/en/articles/vehicle/grnz) (an official government e-services page — a rare primary source, worth fetching directly).

- 520×110mm. Format `111AAA` + 2-digit region code, KZ flag/code band on
  left (Iraq-shaped `ColorBandStrip`).
- Colors: black/white standard, black/yellow for foreign-owned/non-Kazakh
  registrations, white/red diplomatic.
- Current format since 2011/implemented 2012.
