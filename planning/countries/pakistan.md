# Pakistan — evidence dossier

**Status: first pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Pakistan) plus a plate-manufacturer site (xwreflective.com).

## What's known
- Format varies by administrative unit: 2-3 digits + 3-4 letters, letter
  count/digit count not fixed nationally — same shape of variability as
  Egypt (governorate-dependent) and Turkey (6 concurrent formats).
- Letters I, O, U excluded (visual confusion with 1, 0, V) — the same
  validator pattern as Saudi/Russia/Egypt, now a 5th confirmed country.
- Dimensions: 300×150mm (matches the pattern-table's North/Central-America-
  and-Gulf bucket, an odd cross-region coincidence worth noting but not
  acting on).
- Province-specific decorative symbols are load-bearing, not incidental:
  Punjab has used a Datura metel flower motif since 2007; Sindh uses the
  provincial coat of arms on a yellow background.
- Federal plates: red = diplomat, green = federal departments/military/
  police.

## Open questions
- Full province format/color table (only Punjab and Sindh detailed).
- Whether Pakistan counts as federated-by-design (like Mexico/South Africa)
  or has one more-unified national scheme with regional flourishes — not
  yet clear which side of that line it falls on.
