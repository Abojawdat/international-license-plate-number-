# Papua New Guinea — evidence dossier

**First pass, good category coverage.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Papua_New_Guinea).

- 372×134mm, `ABC 123`. Rich category table: government (red `Z` plates,
  per-department codes for police/health/power etc. — sub-categorization
  *within* government, deeper than most dossiers' single government
  entry), diplomatic (maroon), consular (black, `CC`), provincial
  government (red `P`), taxi (white/black), public-motor-vehicles split by
  route type (blue=no fixed route, orange=fixed route — propulsion-style
  encoding but for *route flexibility*, a new dimension entirely),
  motorcycles, trade plates.
- **Personalized plates allowed since 2023** (black on gold) — the most
  recent "vanity plate" introduction found in any dossier.
- Province-letter-prefix system since ~1993, following 1975 independence
  from the unified Territory of Papua and New Guinea scheme (1949-1975) —
  a political-independence-driven format origin, distinct from every other
  "why did the system start when it did" reason found so far.
