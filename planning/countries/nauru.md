# Nauru — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Nauru).

- 372×134mm (Australian standard, Australian stamping dies). 3-era color
  history (white/black 1970-75 → black/white 1975-2015 → black/white
  2015-present, format changing from numeric-only to `ABC 123` in 2015
  despite colors staying constant) — a format change with *no* color
  change, the mirror case of Senegal's 2019 redesign (which changed colors
  but kept the format shape).
- Registration mandatory since 1970.
