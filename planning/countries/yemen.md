# Yemen — evidence dossier

**First pass, flagged for real-world instability.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Yemen).

- 335×170mm (a Wikipedia-hosted photo file even names this exact dimension
  in its filename — unusually direct confirmation for a dimension).
- Colors: blue = private, yellow = taxi, red = trucks/commercial, green =
  government, tan = military.
- **Design is not nationally uniform due to the ongoing civil war** —
  Houthi-controlled north and the internationally-recognized
  government/STC-influenced south reportedly issue different designs. Same
  shape of caution as Syria: "the current system" doesn't have one settled
  answer right now. Treat any single dossier here as provisional and
  possibly needing a north/south split rather than one Yemen entry.
