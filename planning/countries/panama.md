# Panama — evidence dossier

**First pass, one notable finding.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Panama).

- **Format changed in 2013 because Panama ran out of all-numeric plate
  combinations** — a format change driven by *capacity exhaustion*, not
  politics, simplification, or unification like every other "why did the
  format change" case found so far (South Africa, Ethiopia, Sri Lanka,
  Panama's own neighbors). A genuinely new reason category for the
  format-history model to account for.
- Current: `AA0000`, with a letter indicating vehicle type baked into the
  prefix (`M`=motorcycle, `T`=taxi, `B`=bus) — category encoded in the
  serial itself again, like South Korea/Ethiopia's data-field approach.
- Rear-plate-only requirement (front not required) — a third country found
  with an asymmetric front/rear mounting rule (after Zimbabwe's rear-only-
  for-some-vehicle-types and Canada's per-province rule).
- Size reported two ways: 300×152mm (NA standard) and 520×110mm — an
  unresolved dimension conflict, same shape as several earlier ones.
