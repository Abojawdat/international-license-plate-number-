# Madagascar — evidence dossier

**First pass, good category coverage.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Madagascar).

- 520×110mm, `1234 XAB` (province letter embedded mid-serial, not a
  prefix — unusual position). 6 province codes (T=Antananarivo, etc.).
  White/black standard (outlier default, unusual for the region).
- Green diplomatic, white-on-black military (`Z`=gendarmerie, `T`=military
  traffic — letter reused for both province code and category, worth a
  double-check for ambiguity), red-flag government.
- 2014 reform; pre-reform aluminum plates reportedly showed silver
  precipitate where the black coating wore off — a materials-aging detail,
  not relevant to rendering but useful context for "why do real photos of
  old plates look inconsistent."
