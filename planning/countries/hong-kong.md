# Hong Kong — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Hong_Kong), [matriculasdelmundo.com/en/hong-kong.html](https://matriculasdelmundo.com/en/hong-kong.html).

- 520×110mm, British Standard BS AU145a (Hong Kong's UK colonial heritage
  shows directly in the spec, like UK's own BS AU145e).
- Format: 2 letters + 4 digits. Front white, rear yellow (same face-split
  pattern as UK, unsurprising given shared lineage).
- Buses/minibuses: red/white. Taxis/trucks: black/white. Military/police:
  white background.
