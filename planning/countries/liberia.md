# Liberia — evidence dossier

**First pass, one regional-cluster finding.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Liberia).

- 152×300mm (NA standard) — **the source states Nigeria, Liberia and
  Somalia are the only three African countries using NA dimensions**,
  against a continent that otherwise defaults to EU sizing. Worth
  double-checking Nigeria specifically, since `nigeria.md` already flagged
  its own dimensions (152×300, portrait) as possibly wrong/flipped — this
  independent claim actually supports the *size* being real even if the
  orientation was mis-reported.
- Private: `A`-prefix personal, `B`/`C` other categories (likely cargo,
  unconfirmed). Diplomatic: up to 3 digits + `CD`/`CMD` + number, with a
  documented country-code table (01=US, 02=Nigeria, 15=African Union,
  16=EU, 41=UNICEF) — international organizations getting their own
  diplomatic codes alongside countries, not just embassies.
- No color scheme found in this pass.
