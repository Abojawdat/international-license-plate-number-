# Portugal — evidence dossier

**First pass, one genuinely novel finding.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Portugal).

- 520×110mm. Current (2020-present): `AA-00-AA`, no dashes shown between
  groups. Previous (1992-2020): `00-AA-00`, with dashes.
- 2020 format expanded the usable letter set (added W, Y, K) — another
  capacity-extension move, same family as Sweden/Netherlands/Panama.
- **A yellow "registration date" ribbon was added in 1998 and removed in
  2020 specifically because authorities in other countries kept mistaking
  it for an expiration date** — the first "why did the design change"
  reason found that's about *cross-border misinterpretation*, not
  politics, capacity, unification, or simplification. A genuinely new
  category alongside Panama's capacity-exhaustion finding.
- Diplomatic: red on white (not the more common blue/green seen elsewhere).
- 1937-1992 legacy system: white letters on black — inverted from the
  current scheme, a clean 3-era history (pre-1992, 1992-2020, 2020-present).
