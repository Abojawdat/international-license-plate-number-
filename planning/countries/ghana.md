# Ghana — evidence dossier

**Second pass, category gap now closed.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Ghana), plus a targeted category search (ghanaweb.com's plate-meaning explainer, assendelft.co.za's collector guide) that the first-pass search hadn't surfaced.

- Format: 2-letter region code (first letter of region name + "R") + 4
  digits + 2-digit year, e.g. `AS 2567-12` — **year of registration baked
  into the plate number itself**, not just a category/region, a new field
  type not modeled anywhere.
- Front: white/black. Rear: black/white reflective — a face-split pattern
  again, though described with less clean symmetry than UK/HK/Kenya's
  version (worth double-checking, the two color descriptions given nearly
  contradict which face is which).
- Two physical classes: "Long" ~520×130mm, "Square" ~340×170mm; motorcycle
  335×125mm — another multi-size country.
- **Categories**: white/black private, yellow/black commercial (taxis,
  trotros), green government, white/red diplomatic (`CD`), green/white
  agricultural equipment, white/blue motorcycles. `GA` (Ghana Armed Forces)
  and `GP` (Ghana Police) are reserved prefixes the public cannot register
  — a reserved-but-unassigned-to-the-public prefix category, distinct from
  a normal military/police category with its own color.
