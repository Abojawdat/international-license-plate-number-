# Namibia — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Namibia).

- 520×110mm. `N 123-456 A(B)` — fixed `N` prefix + sequential number +
  town/region letter suffix.
- Standard: black on fluorescent yellow. Government: dark green/white,
  agency-specific prefixes (`GRN`, `POL`, `NDF`, `JUD`) — same
  agency-prefix convention as Botswana's `BX`/`BDF` and PNG's per-
  department codes, a recurring African/Commonwealth government-plate
  pattern.
- Personalized plates since 2007: light blue on white acrylic, flag + "NA".
- Pre-independence (1968-1990, as South West Africa): South Africa-style
  system with an `S` prefix — a colonial/administrative-predecessor legacy
  format, another case like Botswana's.
