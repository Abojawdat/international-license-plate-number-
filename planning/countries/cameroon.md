# Cameroon — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Cameroon), [matriculasdelmundo.com/en/cameroon.html](https://matriculasdelmundo.com/en/cameroon.html).

- 520×110mm. Format `AB1234V`/`AB123VH` — regional code + digits + series
  letter(s). **Black on orange** — an outlier default color, unlike almost
  every other dossier's white/yellow-based default.
- Current scheme since 1985. Regional codes: CE, LT, NO, NW, OU, SU, SW.
