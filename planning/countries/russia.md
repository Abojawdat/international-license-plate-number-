# Russia — evidence dossier

**Status: first pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Russia) plus matriculasdelmundo.com (same trusted domain as Iraq/Saudi/Syria) and a dedicated Russian-plate wiki (russian-license-plate.fandom.com).

## What's known
- Format: `L NNN LL` + region code (2-3 digits, e.g. 77 = Moscow) — letter,
  3 digits, 2 letters, region.
- **Only 12 Cyrillic letters permitted** (А, В, Е, К, М, Н, О, Р, С, Т, У,
  Х) — chosen because they have Latin lookalikes. Same shape of restriction
  as Saudi's 17-of-28 Arabic letters and Pakistan's excluded I/O/U — a
  well-established validator pattern now (4th country).
- Dimensions: 520×112mm.
- Colors: white/black standard; blue/white = police; black/white =
  military; yellow/black = public transport; **yellow background specifically
  required for the region-code sub-area** regardless of overall plate color.
- A mandatory blue EU-style "RUS" + flag strip became mandatory in **2025**
  — a recent regulatory change, worth double-checking currency of any
  Russia-specific source given how fresh this is.
