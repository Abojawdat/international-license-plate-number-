# Turkmenistan — evidence dossier

**First pass, one relevant-to-this-package finding.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Turkmenistan).

- 520×110mm, `XX 99 99 XX` (province letters at the end, unusually).
- Colors: black/white standard, white/blue diplomatic, black/yellow
  foreign, **silver/green government** — silver as an ink color is new,
  every other dossier's "silver/gray" mention so far has been a background
  (Saudi's temporary strip), not text color.
- Same Soviet-plates-until-1994 pattern as Kyrgyzstan.
- **Typeface is a hybrid of DIN 1451 and the old French plate font** — DIN
  1451 is directly relevant since this package's own `PlateTypeface` is
  itself DIN-1451-derived (per the README) — worth knowing Turkmenistan
  isn't a totally unrelated design lineage to Iraq's own typeface basis.
