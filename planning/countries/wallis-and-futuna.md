# Wallis and Futuna — evidence dossier

**First pass, good history depth, confirms French DOM-TOM pattern a 6th
time.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Wallis_and_Futuna).

- Current since 1987: 520×110mm, `1234 WF`, black/white front, black/
  yellow rear. Predecessor (pre-1987): white/black both faces.
- French stamping dies, DOM-TOM 3-digit code system — 6th confirmed
  territory (Mayotte, Réunion, French Polynesia, New Caledonia, French
  Guiana).
