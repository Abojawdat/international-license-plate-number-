# Cook Islands — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_the_Cook_Islands).

- 372×134mm (Australian standard). Green/yellow — an outlier color pair
  not seen elsewhere. "Kia Orana" slogan, a Cook Islands Māori greeting —
  a slogan in the indigenous language rather than English/French, distinct
  from every other Pacific slogan found so far (all English).
- New Zealand stamping dies, slashed zero (same typographic convention as
  Samoa's identical NZ-dies case).
