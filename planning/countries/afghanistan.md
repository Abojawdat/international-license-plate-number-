# Afghanistan — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Afghanistan).

- 420×175mm. Bilingual by design: province name in Persian **or** Pashto
  (two official scripts, not one) with a Latin 3-letter code; vehicle class
  shown as a Persian letter + Latin equivalent (or `3` for private).
- Colors: yellow = bus/taxi, red = diplomatic, white = government/lorry/
  motorcycle/private/rickshaw/private-duplicate, white+red text = private
  temporary, blue = UN.
- Political instability caveat applies here too (post-2021 change of
  government) — same caution as Syria/Yemen/Libya on whether "current
  system" reflects 2026 reality.
