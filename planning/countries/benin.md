# Benin — evidence dossier

**First pass, good category coverage.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Benin).

- EU shape, `AB1234`. White/black private, red-on-orange commercial,
  white/blue state transport, white/green diplomatic (`123CMD` — country
  code + mission-rank suffix), `OFFICIEL123` government format (a literal
  word embedded in the serial, not just a prefix code).
- **No regional coding at all** — same as Togo below, a real West African
  regional pattern (2 neighboring countries both skip region codes
  entirely) worth checking against more of the region before assuming
  it's coincidence.
- Country map in flag colors on the right, plus a security sticker between
  registration and country code.
