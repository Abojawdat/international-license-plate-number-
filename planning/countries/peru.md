# Peru — evidence dossier

**First pass, unusually elaborate category scheme.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Peru), [Latam Mobility on low-emission vehicle inclusion](https://latamobility.com/en/peru-modernizes-vehicle-identification-system-with-the-inclusion-of-low-emission-cars/).

- 300×150mm (150×300 also cited, likely same figure transposed — motorcycle
  is smaller, 110×190mm).
- Format: region letter + digit + letter + digits.
- **A color-coded stripe system with 7+ distinct stripe colors** on top of
  the base plate: white=private, yellow=cargo, green=police, red=
  ambulance/fire, orange=display vehicles, white+yellow-stripe=taxi,
  white+green-stripe=urban transit, white+orange-stripe=interprovincial
  transport. This is a two-layer color system (base + stripe) more granular
  than any other dossier found — worth comparing against Indonesia's
  trim-on-top-of-category-color EV mechanism as a similar "layered color"
  approach, though here it's for transport sub-type, not propulsion.
- Actively being updated for low-emission/electric vehicle inclusion — a
  4th distinct EV-encoding effort, not yet detailed.
- Tamper-destructive hologram, same theme as Colombia/Armenia/Tanzania.
