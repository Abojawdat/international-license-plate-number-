# Latvia — evidence dossier

**First pass, most multi-size country found.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Latvia).

- **8 concurrent physical size variants** (types A-H, from 520×110
  standard down to 133×165 for mopeds/off-road) — more concurrent sizes
  than any other dossier (Kuwait/Morocco/Iceland had 3-4).
- Format `AB-1234`. Colors: black/white standard, black/yellow taxi,
  light-blue-on-white-or-yellow EVs (color depends on which base category
  the EV belongs to — a compound EV-encoding case, layering onto whichever
  base category applies rather than replacing it outright), black/red
  diplomatic.
- 2004: EU blue label replaced the Latvian-flag design used until then —
  another flag-for-EU-band swap (joins several EU-accession cases).
