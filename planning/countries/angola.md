# Angola — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Angola), [matriculasdelmundo.com/en/angola.html](https://matriculasdelmundo.com/en/angola.html).

- 520×110mm. Black on white. Format `ABC-01-23-DE` — regional code + two
  digit pairs + letter pair, more segmented than most.
- European-standard, made with Portuguese dies — colonial-heritage
  manufacturing detail, same pattern as Hong Kong/UK (British) and
  Rwanda/Zambia (Belgian/German dies below).
