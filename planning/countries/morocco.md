# Morocco — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Morocco), [matriculasdelmundo.com/en/morocco.html](https://matriculasdelmundo.com/en/morocco.html), [O'Voiture guide](https://ovoiture.ma/en/guides/plaque-immatriculation/).

- Format `NNNNN-X-CC`: serial + Arabic series letter + prefecture code
  (1-99), flanked by two black vertical bars. **The Latin-letter
  transliteration is only displayed when travelling abroad** — a
  conditional dual-script requirement, distinct from Saudi's
  always-both-shown case and Iraq's format-determines-script case. A third
  variant on the `ScriptLayout` question.
- Colors: black on white (private), red (state), blue (Auxiliary Forces),
  yellow (taxis/heavy commercial).
- **Three concurrent physical formats by vehicle type**: one-line 498×110mm
  (cars), two-line 298×210mm (trucks), 180×120mm (motorcycles) — same
  shape of multi-size finding as Kuwait/Jordan/Qatar, now confirmed a 4th
  time.
