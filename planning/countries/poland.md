# Poland — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Poland).

- 520×110mm. First letter = voivodeship (16 total), rest = county — a
  clean 2-tier region code (province then sub-province), more structured
  than most.
- Excludes B, D, I, O, Z (visual confusion) — 7th country with this
  exclusion type.
- **Category encoded as a prefix letter, not just a color**: military
  plates start with `U` instead of a voivodeship code, service vehicles
  (police/border guard/customs) start with `H` — the category *replaces*
  the region code slot entirely, a stronger version of South Korea/
  Ethiopia's embedded-category-character finding.
- Colors: black/white standard, black/yellow classic cars, **black/light-
  green EVs since Jan 2020** (color-swap EV encoding, same mechanism as
  India/Canada-Quebec), red/white temporary, white/dark-blue diplomatic.
- Current EU-compatible system since 2001 (replaced white-on-black 1976
  system) — a 2-era history.
