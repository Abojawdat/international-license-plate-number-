# Ethiopia — evidence dossier

**First pass.** [matriculasdelmundo.com/en/ethiopia.html](https://matriculasdelmundo.com/en/ethiopia.html), [The Reporter Ethiopia](https://www.thereporterethiopia.com/44952/) and [ethiovibes.com](https://www.ethiovibes.com/entertainment/new-ethiopian-license-plate) covering an active redesign.

- Format: 2 Amharic characters + serial + 2 Latin letters, both scripts
  independently encoding region — requires Amharic (Ge'ez script)
  rendering, another script family.
- Colors keyed to an embedded **category number printed on the plate
  itself** (1=taxi/red, 2=private/blue-on-white, 3=commercial/green-on-
  white, 4=government/black-on-white, 5=religious-civic/orange-on-white) —
  same "digit as coded category field" pattern as South Korea's Hangul
  character, here using an actual visible number instead.
- Multiple sizes by vehicle class: 460×110 (passenger), 520×110 (larger),
  340×200 (trailers), 240×130 (motorcycles).
- **New national redesign underway**: dropping regional/city codes
  entirely for one uniform design with an "ETH" code and national map —
  a 3rd confirmed forward-looking-redesign country (after South Africa,
  and in spirit similar to Sri Lanka's code removal).
