# Turkey — evidence dossier

**Status: first pass, single search round**, but well-corroborated across
multiple dedicated province-code sites (a genre of site that exists
specifically because Turkey's scheme is province-driven, which makes them
more reliable for this one fact than a general summary would be).

## What's known
- Dimensions: 520 × 110 mm (matches `PlateFormat.modernLong`).
- Province code 01-81, first two digits (Ankara = 06, Istanbul = 34) — a
  numeric governorate-style code, same shape as Iraq's but 81 provinces
  instead of 19 governorates.
- Multiple concurrent formats depending on province/district: `99 X 9999`,
  `99 X 99999`, `99 XX 999`, `99 XX 9999`, `99 XXX 99`, `99 XXX 999` — six
  live variants of letter-count/digit-count combination, the widest format
  variability seen in any dossier so far (more than Kuwait's multiple sizes
  or Jordan's two row-styles).
- Black text on white; a blue `TR` country-code stripe on the left,
  EU-style but without the 12 gold stars.
- Aluminium, rectangular.
