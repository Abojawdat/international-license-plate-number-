# Bhutan — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Bhutan).

- Format `XX-N-X0000`: category prefix (BP=private, BT=taxi, BG=government,
  RBP=police, RBG=Royal Bodyguard) + region digit + letter + serial.
- Colors: white/red private, black/yellow taxi, yellow/red government,
  white/blue police, white/multi-color Royal Bodyguard, white/blue
  diplomatic.
- **Royal Bodyguard as its own plate category** — a 2nd monarchy-specific
  category found (after Brunei's royal family plates).
- Format itself changed to add a letter (`BP-N-NNNN` → `BP-N-ANNNN`) —
  another capacity-extension case.
