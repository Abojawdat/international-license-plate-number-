# Myanmar — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Myanmar).

- 358×162mm. Format: 3-letter region code + township numeral + 6-character
  serial, make/model text below the serial — a plate that includes
  free-text vehicle description, not seen elsewhere.
- Colors, by use rather than pure ownership category: white/black =
  embassies/organizations, yellow/black = religious vehicles, blue/white =
  touring, black/white = private, red/white = hire/trailer/hearse — an
  unusual grouping (hearses and trailers sharing a color with hire
  vehicles).
- Current format only since **July 1, 2021** — very recent, worth noting
  given Myanmar's political situation post-2021 coup (same caution as
  Syria/Yemen/Afghanistan/Libya).
