# Isle of Man — evidence dossier

**First pass, deepest format-history count found.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_the_Isle_of_Man).

- Current (since Aug 1987): 520×111mm, letter + `MN` + up to 3 digits +
  trailing letter. Excludes I, Q, S, Z throughout; A not used initially,
  O not used finally — a positional exclusion rule (which letters are
  banned depends on where in the serial they'd appear), more granular
  than a flat exclusion list.
- Black/white front, black/yellow rear; pre-Feb-1990 vehicles may use
  white-on-black. Trade plates: red/white.
- Optional since April 2004: Manx flag + triskelion symbol + `GBM` code.
- **~12 major format changes since registration began in 1906** — the
  highest explicitly-counted number of format eras found in any dossier
  (vs. Kuwait's/Greece's/DR Congo's 3-5 eras, described but not counted
  this precisely).
- Lieutenant Governor's car: `MAN-1`.
