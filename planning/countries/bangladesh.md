# Bangladesh — evidence dossier

**First pass.** [WikiMili mirror of Wikipedia](https://wikimili.com/en/Vehicle_registration_plates_of_Bangladesh), [ResearchGate BRTA diagram](https://www.researchgate.net/figure/BRTA-standard-license-plate_fig2_338096474) (an academic figure — worth pulling directly), [Zenodo Bangla plate dataset](https://zenodo.org/records/7110401) (a real labeled photo dataset — potentially very useful for photo verification later, not just this one country).

- Two-line format: city/district + Bengali vehicle-class letter (line 1),
  6-digit number (line 2). **Requires Bengali script rendering** — a 5th
  non-Latin/Arabic script family confirmed (after Hanzi, Hiragana,
  Cyrillic, and now Bengali).
- White/black = private, green/black = commercial, red/white "GOVT" =
  government, white/black + "RR" prefix = diplomatic.
- Dimensions given only as an aspect-ratio range (1.6-2.15), not a fixed mm
  figure — less precise than most dossiers so far.
