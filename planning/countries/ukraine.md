# Ukraine — evidence dossier

**First pass, live wartime changes — treat as time-sensitive.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Ukraine).

- 520×112mm. Format `AB 1234 BC`, region prefix + 4 digits + serial suffix.
  Uses **only Cyrillic characters that are shaped identically to Roman
  letters** — the same cross-script-visual-compatibility exclusion
  principle as Greece, independently arrived at.
- Region codes **changed in 2013 and again in 2021, with some
  combinations (BP, CC) deliberately omitted for political sensitivity** —
  a 4th distinct exclusion-reason category (after visual-confusion,
  cultural-taboo, cross-script-compatibility): *avoiding an unwanted
  reading* (these read like other loaded abbreviations/acronyms).
- **Diplomatic color reportedly changed to white-on-olive-green as of
  April 2026** — inside this project's own current year; a "volunteer
  military" category (white on dark green) also reported, tied directly to
  the ongoing war. Both details need re-checking closer to any actual build
  date rather than trusted as settled, given how recently and rapidly
  they're changing.
- 4 registration systems since 1991 (Soviet-adapted 1992 → 1995 redesign →
  current 2015 system, Vienna-Convention-compliant) — another deep
  format-history case.
