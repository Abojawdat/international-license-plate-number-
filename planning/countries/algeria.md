# Algeria — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Algeria), [matriculasdelmundo.com/en/algeria.html](https://matriculasdelmundo.com/en/algeria.html), [cockpitdz.com Jan 2023 update](https://www.cockpitdz.com/en/post/algerian-license-plate-standards) (a recent, dedicated technical source — worth fetching directly).

- 520×110mm. Format: 3 groups of digits (wilaya 1-58 + year/category code)
  — **numeric only, no letters at all**, one of very few dossiers found
  with this property (source explicitly calls this out as unusual).
- Front: black on white. Rear: black on yellow (since 2009) — same
  face-based color-split pattern as UK, third country with this now.
