# Tajikistan — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Tajikistan).

- 520×110mm, `1234AB56`. Private vs. legal-entity plates distinguished by
  digit-count-at-the-start (3 digits vs 4) rather than a letter prefix —
  a numeric-length-based category distinction, a new mechanism. Public
  transport: black/orange, `TT` code.
- 2014 update added a **security chip beneath the country code** — another
  embedded-electronics case (joins Azerbaijan's RFID).
- Soviet plates used until 1996, then a Russian-influenced design, then
  2009-2010 introduced the Tajik flag/TJ code.
