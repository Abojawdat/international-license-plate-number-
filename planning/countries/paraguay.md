# Paraguay — evidence dossier

**First pass, confirms Mercosur finding a 4th time.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Paraguay).

- Since 2019: the Mercosur blank (400×130, blue top strip, FE-Engschrift
  variant) — 4th country confirmed (after Brazil/Argentina/Uruguay).
  Security features go further than the others found so far: watermark +
  hot-stamped foil with diffractive/sine-wave effects, a physical (not
  digital) anti-counterfeiting layer.
- Previous (2000-2019): national-only system, `ABC 123`, red on white,
  320×150 (cars)/200×130 (motorcycles) — introduced specifically to combat
  vehicle smuggling and centralize municipal-issued plates, a
  law-enforcement-driven format origin (Law 608/95), a new "why did this
  system start" reason.
