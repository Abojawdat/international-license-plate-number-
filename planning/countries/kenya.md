# Kenya — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Kenya), several Kenyan finance/news explainers (biznakenya, money254, monolithafrica) agreeing on the scheme.

- Format `LLL NNNL`. White front / yellow rear for private (4th
  face-color-split country).
- Colors: blue/white = parastatal, yellow/black = public service vehicles,
  red/white = diplomatic, **green/white = both EVs and motorcycles
  together** — an odd shared category (propulsion type and vehicle class
  sharing one color), different from every other EV-encoding case found.
- County government vehicles: county code + "CG" suffix.
- Two sizes: rectangular 520×110mm, square 250×200mm.
