# Albania — evidence dossier

**First pass, good category coverage.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Albania).

- Current since 2011: 520×110mm, `AB 123 CD`, black/white private.
  Category suffix/prefix letters double as literal Albanian-language
  abbreviations: `MB` = Makinë Bujqësore (agricultural) *or* Ministria e
  Brendshme (police, Ministry of Interior) depending on position —
  category codes drawn from real words, not arbitrary letters, joining
  Cambodia/Tunisia's language-embedded-in-format cases.
- **1993-2011 plates required regional district abbreviations and remain
  valid today** even though new plates don't carry them — another
  discontinued-but-still-valid case (joins Fiji, Albania's own agricultural
  format above uses no region code either) — this is specifically about
  the *region abbreviation* becoming optional/removed while old plates
  stay legal, distinct from a full format replacement.
