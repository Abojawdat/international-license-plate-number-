# Tonga — evidence dossier

**First pass, one data-quality flag.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Tonga).

- 372×134mm (Australian standard). White/black.
- Letter-prefix category system (B=buses, C=private cars, G=trailers,
  H=heavy cargo, J=cargo, L=light cargo, MC=motorcycles, P=state, R=rental,
  T=taxis, V=three-wheeled) — **the automated pass rendered some of these
  as Cyrillic look-alike characters (В, С) which is almost certainly a
  transcription artifact, not real Cyrillic use in Tonga** (no other
  source or plausibility supports Tongan plates using Cyrillic). Flagged
  rather than trusted — treat the plain-Latin B/C reading as correct until
  photo-confirmed.
- Diplomatic: country-code prefixes (AUST, NZ, UK, USA, EEC), white front/
  yellow rear. Royal: `HM` or crown symbol. PM: `PM` + 2 digits — a 3rd
  Pacific head-of-government-specific plate case (after Guyana's
  President/PM, PNG doesn't have one specifically flagged).
- 1967 first issued; **owner is legally responsible for having the plate
  made** — same self-manufacture rule as Vanuatu and Kiribati (see below),
  a real Pacific-islands pattern, not a one-off.
