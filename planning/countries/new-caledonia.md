# New Caledonia — evidence dossier

**First pass, confirms French-DOM-TOM code pattern.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_New_Caledonia).

- 520×110mm, French stamping dies, both faces white/black (unlike French
  Polynesia's front/rear split — the two French Pacific territories don't
  share identical designs despite the shared numbering scheme).
- Code `988`, from the same French overseas-territory 3-digit system
  (originally shared `97`) as French Polynesia's `987` — confirms that
  finding as a real system, not a one-off coincidence.
