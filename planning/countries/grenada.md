# Grenada — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Grenada).

- 152×300mm (NA size) using British-plate typeface — a hybrid of American
  dimensions and British lettering, an explicit cross-standard combination.
  Front black/white, rear black/yellow.
- History: 1974 porcelain plates (orange/white) → 2010 redesign
  (black/orange) — porcelain is a material not seen in any other dossier
  (everything else is aluminum/plastic/reflective sheeting).
