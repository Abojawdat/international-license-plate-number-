# Djibouti — evidence dossier

**First pass, two novel findings.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Djibouti).

- 520×110mm. **No country code identifier on the plate at all** — the
  only confirmed case of a country skipping this entirely (every other
  dossier has at least a 2-3 letter code somewhere on the design).
- **2023: inverted from black-on-white to white-on-black** — a very recent
  full color inversion, distinct from every other "recent change" case
  (not a redesign of format/region codes, purely the ground/ink swap).
- Typeface: FE-Schrift for the alphanumerics (6th+ country with this face)
  **and Arabic text specifically set in Square Kufic** — the first named,
  specific historic Arabic calligraphy style found in any dossier (Iraq's
  own legacy Arabic rendering falls back to a generic platform font; this
  is a deliberate typeface choice).
