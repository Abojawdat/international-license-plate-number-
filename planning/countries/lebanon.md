## What's known
- Format: `[Letter] [Number]`, e.g. `T 789012` — letter is a **governorate/
  municipality code** (B = Beirut, Z = Zahleh, etc.), similar in spirit to
  Iraq's numeric governorate code but Latin-letter-based instead.
- Modernized Dec 27 2017: blue vertical band on the left with the Lebanese
  cedar emblem, "لبنان" (Lebanon) in Arabic, and a vehicle-classification
  indicator — architecturally close to Iraq's `ColorBandStrip` concept
  (band + emblem + country name), a good candidate for reusing that shape
  rather than inventing a new one.
- Rest of plate: white background, bold Arabic numerals next to the Latin
  governorate letter.
- Category colors: red = taxi/public transport, green = rental, yellow =
  dealership, blue = test-drive/temporary.
- Special government plates: `J` prefix = judge-owned, `MP`/`AG` = minister/
  parliament member, `R` + number = religious clergy — a granular
  government-official sub-scheme with no real equivalent seen elsewhere yet.
