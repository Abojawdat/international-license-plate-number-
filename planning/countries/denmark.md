# Denmark — evidence dossier

**First pass.** [Wikipedia](https://en.wikipedia.org/wiki/Vehicle_registration_plates_of_Denmark).

- 520×110mm, `AB 12 345`. Numbering was type-based before 2012, then fully
  randomized — a capacity/administrative-simplification change, joining
  the growing "why formats change" catalogue.
- Diplomatic: blue/white, with numbers 76/77 specifically reserved.
- **Autonomous territories have their own schemes**: Faroe Islands use
  `FO` + a distinct 2-letter/3-digit format; Greenland uses reserved
  `GR`/`GL` letters under the Danish `DK` code — a within-country
  sub-scheme for autonomous territories, a smaller-scale version of the
  UAE/US/Canada federation pattern worth remembering applies below the
  country level too, not just at it.
